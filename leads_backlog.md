# Leads backlog

A sourcing backlog for future daily rounds, built 2026-10-07 per
Nikolai's request ("find 100 candidates"). Source: Turismo Roma's
official "botteghe storiche" historic-shops directory
(`turismoroma.it/it/tipo-luogo/botteghe-storiche`, all 5 pages, ~136
businesses total), cross-referenced against `clients/` to remove
duplicates. 91 are genuinely new and untried (below), another ~45
were already in `clients/` (listed at the bottom so they're not
re-sourced by mistake), and a handful were checked today and are
either dead ends or worth a specific retry (also listed below).

**What this is, and isn't:** this is a sourcing list (name, address,
category), not verified leads. None of these have had the real-email
/ real-website / photo-sourcing pass done yet. Each one still needs
the full process before being built: confirm a real first-party email
(not a directory listing), confirm the site is actually bad/missing
(not just old-looking, not already well-maintained, per the
`emiliozzi`/`poggi-belle-arti`/`tebro`/`bedetti` lesson from rounds
41-43), then the branding/photo pass. Pick 1-2 per day from this list,
verify, and either build or cross off with a reason, same as every
other round.

## How to use this list

1. Pick a candidate, `grep` its name against `clients/` first in case
   it was picked up since this list was written.
2. Search `"<name>" roma sito email contatti` and verify directly
   (curl/WebFetch on their own domain, not just the search summary).
3. If it has a real first-party email and a genuinely bad/missing
   site, build it. If not, mark it below (dead domain / no email /
   well-maintained / duplicate) so the next round doesn't retry it.
